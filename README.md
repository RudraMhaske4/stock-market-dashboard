# 📈 Stock Market Dashboard

An AI-powered stock analysis and trading simulation dashboard built with Streamlit.

## 🚀 Features
- 📉 Real-time stock data via Yahoo Finance
- 🕯️ Candlestick + Volume charts
- 📊 RSI & Moving Average indicators
- 🤖 Random Forest ML price prediction
- 💰 Investment profit/loss calculator
- 🛒 Buy/Sell portfolio simulator
- 💬 AI chatbot powered by LLaMA 3.1 (Groq)

## 🛠️ Tech Stack
- Python
- Streamlit
- Plotly
- Scikit-learn (Random Forest)
- Groq API (LLaMA 3.1)
- yFinance
- Pandas & NumPy

## ▶️ Run Locally

### 1. Clone the repo
git clone https://github.com/RudraMhaske4/stock-market-dashboard.git

### 2. Install dependencies
pip install -r requirements.txt

### 3. Create .env file
GROQ_API_KEY=your_key_here

### 4. Run the app
streamlit run Dashboard.py

## 📊 How It Works
1. Enter any stock symbol (AAPL, TSLA, RELIANCE etc)
2. Select timeframe
3. Dashboard shows charts, indicators and ML prediction
4. Use AI chatbot to ask questions about the stock
5. Simulate buying and selling with virtual $10,000
