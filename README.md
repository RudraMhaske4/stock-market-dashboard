A personal project I built in my first year of AIML to explore how stock 
analysis, machine learning, and AI can work together in one application.
It pulls real-time market data, runs a prediction model, and lets you 
chat with an AI assistant about the stock — all in one Streamlit dashboard.

## What It Does

- Pulls live stock data for any ticker (AAPL, TSLA, RELIANCE, etc.)
- Displays Close Price, Candlestick and Volume charts
- Calculates RSI and Moving Averages (MA20, MA50)
- Predicts next price using a Random Forest model (with train/test split and RMSE score)
- Shows Buy/Sell signals based on RSI and MA logic
- Investment calculator — enter amount, see predicted profit or loss
- Simulates a portfolio with virtual $10,000 (Buy/Sell shares)
- AI chatbot powered by LLaMA 3.1 that answers questions using live stock context

## Running Locally

Clone the repo

    git clone https://github.com/RudraMhaske4/stock-market-dashboard.git
    cd stock-market-dashboard

Install dependencies

    pip install -r requirements.txt

Create a .env file in the project folder

    GROQ_API_KEY=your_key_here

Run the app

    streamlit run Dashboard.py

## How the ML Works

The model uses the previous 3 closing prices (Prev1, Prev2, Prev3) as 
features to predict the next closing price using Random Forest Regressor.

- Train/test split: 80/20
- Evaluation metric: RMSE
- Signals generated by combining ML prediction + RSI + MA20
